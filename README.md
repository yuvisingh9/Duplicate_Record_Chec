# Duplicate Record Check

## Project Overview
This project focuses on identifying duplicate records, documenting duplicate entries, and preparing a cleaned dataset.

## Objectives
- Detect duplicate records.
- Generate a duplicate report.
- Remove duplicate entries.
- Maintain an audit log.
- Verify the cleaned dataset.

## Tools Used
- Microsoft Excel
- Python
- Pandas

## Dataset Summary
| Metric | Result |
|---|---:|
| Original Records | 55 |
| Duplicate Records | 5 |
| Records Removed | 5 |
| Cleaned Records | 50 |

## Deliverables
1. Duplicate Record Check Excel Workbook
2. Cleaned Retail Sales CSV

## Key Learning
Learned how to identify duplicate records, maintain data quality, document changes, and prepare clean datasets for analysis.

## Conclusion
Duplicate records were identified and removed successfully, resulting in a cleaned dataset containing 50 unique records.

*Note: This project uses a demonstration retail sales dataset.*
